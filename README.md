#FPGA-Based Real-Time Edge Detection Using Sobel Algorithm

#Project Overview

This project implements a real-time image edge detection system using the Sobel algorithm on an FPGA. An OV7670 camera is used to capture the image, while the Terasic DE2-115 FPGA development board performs image capture, storage, processing, and VGA display.

The captured image is stored in a frame buffer and processed using a Sobel edge detection algorithm. The resulting edge-detected image is displayed on a VGA monitor.

# Objective

To design and implement an FPGA-based real-time edge detection system using the Sobel algorithm, which captures an image using an OV7670 camera, processes the image on the FPGA, detects significant edges, and displays the processed image on a VGA monitor.

Working Principle

The system operates in the following sequence:

The OV7670 controller configures the camera through the SIOC and SIOD interface.

The OV7670 generates the camera clock and image data signals.

The camera capture module receives D0-D7, PCLK, HREF, and VSYNC.

Captured pixel data is converted into the required RGB format.

The image is stored in a dual-port frame buffer with a resolution of 320 × 240.

The VGA timing module reads the stored image and generates VGA synchronization signals.

The image is processed by the Sobel edge detection module.

Sobel calculates horizontal and vertical image gradients to identify edges.

The processed pixel data is converted into VGA-compatible RGB signals.

The final edge-detected image is displayed on a VGA monitor.

🧮 Sobel Edge Detection

The Sobel algorithm uses two 3 × 3 convolution kernels to detect horizontal and vertical changes in pixel intensity.

Horizontal Gradient (Gx)

[-1   0  +1]
[-2   0  +2]
[-1   0  +1]

Vertical Gradient (Gy)

[-1  -2  -1]
[ 0   0   0]
[+1  +2  +1]

The edge magnitude is calculated using the horizontal and vertical gradients:

Edge Magnitude = |Gx| + |Gy|

The system compares the calculated edge magnitude with a threshold to determine whether a pixel represents a strong edge.

Camera Control Signals

SIOC – Serial clock for camera configuration

SIOD – Bidirectional serial data line

XCLK – Clock supplied from FPGA to camera

VSYNC – Indicates frame timing

HREF – Indicates valid line/pixel data

PCLK – Pixel clock generated by camera

PWDN – Controls camera power-down mode

RESET – Camera reset control

📺 VGA Output

The system generates a 640 × 480 VGA display.

The captured image is stored at 320 × 240 resolution and displayed using 2× scaling.

320 × 240 Frame Buffer
          ↓
       2× Scaling
          ↓
      640 × 480 VGA

🎛️ FPGA Controls

The DE2-115 switches and LEDs are used for control and debugging.

SW[1] – Freeze/live frame control

SW[2] – VGA test-pattern selection

KEY[0] – Camera configuration resend

LEDs – Camera configuration, capture, clock, frame, and signal activity indicators
